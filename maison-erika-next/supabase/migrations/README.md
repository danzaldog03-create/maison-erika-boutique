# Migraciones generadas por Supabase CLI

Este directorio debe contener únicamente archivos creados con
`supabase migration new` o `supabase db pull` y revisados antes de versionarse.

La migración de seguridad de la Etapa 1 se mantiene temporalmente en
`../pending/harden_profile_roles_and_auth_trigger.sql`. Debe copiarse aquí sólo
después de generar su nombre oficial con la CLI, tras crear el baseline remoto.
